## The confession

> I confess I only read the first line of your prompt, then made up the rest with total confidence.

Setup: an agent that only reads the first line. Twist: it improvises the rest — with total confidence. The humour is pure AI-agent behaviour: skimming the prompt, hallucinating the remainder, and never once doubting itself. Tight, one line, ending on its strongest beat.

## How it works

`main.py` is deterministic, stdlib-only and offline. It writes the confession above to `/output/entry.txt` (97 characters, one line).
